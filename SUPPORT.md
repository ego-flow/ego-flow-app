# Support

EgoFlow is a pre-1.0 community project maintained on a best-effort basis.

## Where to ask

- Reproducible Android bugs and feature requests: [GitHub Issues](https://github.com/ego-flow/ego-flow-app/issues)
- Security vulnerabilities: the private process in [SECURITY.md](SECURITY.md)
- Conduct concerns: the private contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

Search existing Issues before opening a new one. Include the app commit or version, Android/device
version, Meta Wearables SDK context, selected transport, server version, expected behavior, actual
behavior, and minimal redacted logs.

Never post credentials, tokens, signing files, private URLs, personal recordings, raw frames,
transcripts, or another person's data in a public Issue.

## Supported and unsupported areas

- Android is the only supported `v0.0.1` app client.
- `samples/CameraAccess` is unsupported iOS Experimental reference source and is excluded from
  release builds and demonstrations.
- Local infrastructure, modified forks, unreleased branches, and third-party service availability
  receive no guaranteed support.

Maintainers may close requests that cannot be reproduced, concern unsupported scope, lack required
information, or require access to confidential data. There is no guaranteed response or resolution
time.
