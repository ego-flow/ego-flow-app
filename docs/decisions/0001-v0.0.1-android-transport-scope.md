# ADR-001: Limit v0.0.1 Android acceptance to RTMP and HTTP

## Status

Accepted

## Date

2026-08-26

## Context

The Android repository contains RTMP, HTTP, and WHIP transport modules. The `v0.0.1` Record UI,
however, exposes only an RTMP/HTTP toggle: `SettingsManager.recordTransportMode()` maps every other
stored value to RTMP, and `normalizeRecordTransportMode()` persists that normalized choice. The
clean local release E2E qualified RTMP and HTTP with physical Meta glasses, while WHIP has neither a
shipping selection nor real-device WebRTC/ICE acceptance evidence.

The first PoC also runs with microphone streaming disabled. Microphone-enabled RTMP behavior and
its known timing failure are intentionally outside the `v0.0.1` repair and acceptance scope.

## Decision

- Support RTMP/RTMPS and HTTP chunk upload in the `v0.0.1` Android product UI.
- Keep `:transport-whip` and its unit tests as dormant experimental source, but do not present WHIP
  as selectable, release-qualified, or part of the contest demonstration.
- Keep microphone streaming off in the first-PoC acceptance flow and do not treat microphone runs
  as release evidence.

## Alternatives considered

### Restore WHIP as a supported v0.0.1 choice

This would require restoring a UI selector and completing physical-glasses WebRTC/ICE, live
playback, stop/finalization, and failure-path E2E. That is a larger release-scope change than the
current PoC needs.

### Remove the WHIP module

Removing it would reduce dormant code, but would also discard a useful transport implementation
and its tests before a later qualification decision. Keeping it clearly marked as experimental is
the smaller reversible choice.

## Consequences

- Public release documents and the changelog describe RTMP/HTTP as the supported transports.
- Module inventories and SBOM material may still list `:transport-whip`; inclusion in source or a
  build is not a support claim.
- Future WHIP activation requires an explicit UI/config change, real-glasses E2E evidence, and a
  new release-scope decision.
- The first-PoC checklist and evidence use microphone-off sessions only.
